# Basemap tiles

Builds `public/map/world.pmtiles`, the vector basemap every map surface draws.

## Running it

```
make map-tiles
```

That builds a container pinning tippecanoe and runs `build.sh` inside it. The
container is the only place the toolchain is required: it is **not** a CI
dependency and `make test` never invokes it. Run this only when the sources or
the build flags change, and commit the result.

## What it reads

The four Natural Earth 110m files already committed under
`build/mapdata/source/`, and nothing else. **No network access is required**,
because the label anchors this needs (`ADMIN`, `LABEL_X`, `LABEL_Y`,
`LABELRANK`) are already carried by `ne_110m_admin_0_countries.geojson`.

`build/mapdata/` is a separate generator with a separate output (`admin.go`, the
country polygons the Region lookup uses). The two share source files and nothing
else.

## What it writes

`public/map/fonts/NotoSans-Regular/` holds four signed-distance-field glyph ranges,
about 350 KB, generated by `glyphs.js` from the `fonts-noto-core` package inside
the container. The font is not downloaded: it comes from the pinned base image,
which is also where its licence text comes from.

MapLibre resolves `glyphs` as a URL, so without these the labels have no
typeface to be drawn in. `public/map/fonts/LICENSE.txt` ships beside them
because SIL OFL 1.1 requires the notice to travel with any Modified Version, and
SDF ranges generated from a TTF are one. Noto declares no Reserved Font Name,
which is what allows the generated ranges to keep the `NotoSans-Regular` name.

One archive, four layers:

| Layer | Geometry | Attributes |
|---|---|---|
| `land` | polygons | none |
| `lakes` | polygons | none |
| `boundary_lines` | lines | none |
| `country_labels` | points | `name`, `rank` |

## Two things in here are decisions, not mechanics

**Every country gets a label.** `labels.py` applies no `LABELRANK` cutoff and
fails the build if any admin-0 feature is dropped. The only feature above rank 6
is Western Sahara, so any cutoff omits exactly one country and that country is a
disputed territory. It would also put the label set out of step with the Region
row, which names a country from `ADMIN` over this same feature set. Density is
the renderer's collision index's job, and `rank` is carried through as a draw
priority for it.

`--drop-rate=1` exists for the same reason: tippecanoe's default drops points at
low zoom, which left one label of 177 in the z0 tile.

**Geometry layers carry no attributes.** `strip.py` removes them. Lakes carry 37
fields and boundary lines 38, none of which the style reads, and among the
boundary-line fields are 34 `FCLASS_*` columns holding Natural Earth's
per-country classifications of disputed boundaries. This plugin takes no
position on those, and not shipping the data is how you take no position.
Stripping them also cut the archive by 45%.

## Shape of the archive

`build.sh` produces, and the reader is entitled to assume:

- PMTiles spec version 3, tile type MVT
- **a single root directory, zero leaf directories**
- clustered, gzip tile compression
- zoom 0 through 6

That shape is deliberate and worth preserving: it is what keeps a from-scratch
reader down to a header parse, one directory decode and an inflate, which is the
fallback if the `pmtiles` package ever has to be dropped.
