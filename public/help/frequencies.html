Frequencies

A radio frequency behind FREQ: becomes a link that names its band and any known allocation. The label is required, because a bare number is any decimal.

Setting: EnableFrequency. To see what your own server does, run /tactical-fusion examples. Every example below is one of that command's own rows.

The grammar

Write FREQ: in upper case, then the frequency. A decimal is megahertz and a whole number is kilohertz, and either may carry its own unit:

WriteRead as
FREQ:121.5121.500 MHz, the aeronautical emergency frequency
FREQ:118.3118.300 MHz, VHF air band, a 25 kHz channel
FREQ:243.0243.000 MHz, the UHF military emergency frequency
FREQ:118.300 MHZThe same as FREQ:118.300; the unit stays in the link's label because it is what you wrote
FREQ:8992 KHZ8.992 MHz, HF aeronautical
FREQ:8992The same: a whole number is kilohertz

The label is consumed, as the airfield labels are: FREQ:121.5 becomes a link whose text is 121.5. A // after the token, the USMTF set terminator, stays outside the link. Two frequencies on one line both link. Anything below 2 MHz or above 1,300 MHz is left alone, which covers every aeronautical band and nothing that is only a number.

Deliberately declined

InputWhy
121.5 on its ownThere is no bare grammar, permanently. A decimal is any decimal, and rewriting one is corruption.
freq:121.5Lower case. The label is read in upper case only, as every other label is.
FREQ: 121.5Nothing may follow the colon, for the reason the airfield labels give.
FREQ:121.5 GHZA unit this plugin does not read. The unit is consumed and the whole token refused, rather than linking 121.5 and leaving GHZ outside to contradict it.
FREQ:121.5 KHZ, FREQ:8992 MHZOutside 2 MHz to 1,300 MHz once the unit is applied.
FREQ:121.5678Four decimals is finer than any channel plan. Refused whole rather than truncated to three.
FREQ:10901,090 kHz, below the range. Write FREQ:1090.0 for 1,090 MHz, which links and is named as outside the aviation bands.

What the hover and the panel show

Hover the link and the card says the frequency in megahertz and its band, and the allocation when it is one the plugin names. Click it and the panel shows the token as written, the band, the frequency in megahertz and in kilohertz with a copy button on each, the channel spacing inside the VHF air band (25 kHz, or 8.33 kHz for a frequency that is not a multiple of 25), and the allocation. Everything is derived from the token in your browser; nothing is fetched and there is no API route. See the sidebar panel for the shared mechanics.

A frequency inside no band is linked and named as outside the aviation bands this plugin names, so the link still gives the readings. The bands follow the ITU Radio Regulations' aeronautical allocations and the FAA Aeronautical Information Manual, and the same table is held on both the server and the web app by a test.
