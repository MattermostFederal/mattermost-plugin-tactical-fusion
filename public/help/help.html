Mattermost Tactical Fusion

Enriches conversations with mission-relevant context, in place, as people write.

Today the plugin recognizes three kinds of thing: times, coordinates and airfield codes. Write a date-time group and it becomes a link that opens a panel showing that instant in every timezone you care about, with a countdown to it. Write a coordinate in any of the recognized notations and it becomes a link showing the same position in the others, including its military grid reference. Write an ICAO airfield code behind a USMTF field label and it becomes a link naming the field and where it is.

CoT, IP intelligence and CVEs are described in the plugin's roadmap but are not implemented.

What a decorator does

A decorator finds a token in a message, rewrites it into a link, and renders the detail behind that link. Post this: 

Rendezvous at 091630ZAUG26, DZ is 3510N07901W

and what is stored is this:

Rendezvous at [091630ZAUG26](/plugins/com.mattermost.plugin-tactical-fusion/decorate/dtg?...),
DZ is [3510N07901W](/plugins/com.mattermost.plugin-tactical-fusion/decorate/location?...)

Readers see the original text, unchanged, as a link. Clicking opens the right-hand sidebar with the detail: a timezone table for a time, the other notations for a coordinate. The browser never navigates away from the channel.

The one thing worth understanding

Decoration happens on the server, and it rewrites the stored message.

That is a deliberate trade. It is the only way the link reaches clients that never run the plugin's web bundle, notably the mobile app. The cost is that the link is really in your message, not painted on top of it.

Four consequences follow, and all four surprise people at least once:

You will noticeBecause
Editing a post shows you raw markdown, not the time you typed. The link is the stored text. Deleting the link syntax while editing is the supported way to opt a post out.
Editing a post does not re-decorate it. On purpose. Re-decorating would mean transforming text you deliberately authored.
Messages posted before the plugin was installed are untouched. Only new posts pass through the hook. There is no backfill.
Uninstalling the plugin leaves links that go nowhere. The text stays; the route serving it does not. Switching a format off is the safe way to stop new decoration, because it leaves the history working.

What is never touched

A token inside a code block, a link, or inline HTML is left exactly as written. The protection is per span, not per message, so a message containing both a pasted URL and a date-time group gets the date-time group linked and the URL left alone. The full list is on the formats page.

The same caution runs through what is recognized at all. A coordinate has to be unmistakably one before it is rewritten, which is why 34.05, -118.25 is deliberately left alone: a false positive here edits a message somebody wrote. If something you expected to link did not, /tactical-fusion check will tell you which rule decided it.
