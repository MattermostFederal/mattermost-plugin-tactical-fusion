Notes

A note is a link that carries its own markdown. Point at it and the hover card renders that markdown exactly as Mattermost renders a post: tables, lists, headings, quotes, code and emoji.

Nothing in an ordinary message becomes a note. A note is written on purpose, with /tactical-fusion note or by another plugin through the bridge. To see some, run /tactical-fusion examples.

Writing a note

Give the command a label, a |, and the markdown. The label becomes the link text; everything after the first | is the note, so a table's own pipes are safe. The markdown may run over several lines. 

/tactical-fusion note DCA | **DCA**: Defensive Counter Air

The command posts the link to the channel as you, in the thread you ran it from. A table is written the same way, across several lines: 

/tactical-fusion note fuel state | | Tail | Fuel |
|:--|--:|
| 101 | 12,400 lb |
| 102 | 9,800 lb |

Limits

RuleWhy
Up to 1,000 characters of markdownThe markdown travels URL-encoded inside the link, which can triple its length, and the whole link has to fit in one post.
A one-line label with no |The first | is where the markdown starts.
Never edited in placeThe markdown is the link. Changing a note means posting a new one.

What the hover, the panel and the page show

WhereWhat
HoverThe rendered markdown, scrolling past a few hundred pixels so a long table stays inside the card.
SidebarThe rendered markdown, then As posted: the markdown source, with a copy button.
Standalone pageThe markdown source, as text. The page is served outside Mattermost, where its markdown renderer is not available, so it shows what the note says rather than a second rendering that could differ.

The rendering is Mattermost's own, so it follows the same rules as a post: raw HTML is shown as text, never run, and an image is fetched the way an image in a post would be.

The examples

/tactical-fusion examples posts three messages of notes: a glossary that expands DCA, OCA, ISR, ACO, ATO, COP, ROE, BDA, CAS and TST; two tables, a squadron readiness board and a range schedule; and a weather brief and a launch checklist that use headings, lists, a task list, a quote and inline code.

Settings and troubleshooting

Notes have no switch. Nothing is recognized in message text, so there is nothing to turn off; a link already posted keeps working. The command's refusals are TF-16007 to TF-16010, and the page's is TF-17006.
