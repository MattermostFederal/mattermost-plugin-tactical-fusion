Coordinates

Twelve coordinate grammars, what each renders, and why the declined list is as long as it is.

Every grammar on this page can be switched off individually in the System Console. See Admin Settings. To see what your own server does rather than what this page says, run /tactical-fusion example-details. Every example below is one of that command's own rows.

The twelve grammars

Some are recognized on their own. Others are recognized only behind a USMTF field label, because bare they would rewrite text that is not a coordinate at all.

Settings: EnableLocationDDSigned and EnableLocationLatLon

Four fractional digits are required on both halves, which is about 11 meters. Fewer than that and the shape is indistinguishable from an ordinary pair of numbers in a sentence, and decoration rewrites the stored message permanently.

A decimal point is required even when hemisphere letters are present, because N, S, E and W are also newton, siemens, east and watt. Load 12 N, 5 W is a load rating, not a position.

Spaced or run together, with symbols or without. The typographic variants are accepted because a phone keyboard produces them unbidden: the prime and the smart single quote for minutes, the double prime and the smart double quote for seconds, and both the degree sign and the masculine ordinal for degrees.

A confidence-bearing token such as 2120N9-15757W7 states how well each axis is known. The digits are read and shown as a separate row; they never move the position, so it is byte for byte the position 2120N15757W names.

Field labels

A label is matched and then dropped, so the link text is the token alone. These are recognized, longest first so that LATDS cannot lose to LATD:

LATDS, DEPLATM, ARRLATM, VLATD, VLATM, VLATS, VGEOT, DMPID, GEOK, LATD, LATM, LATS, DEPUTMO, ARRUTMO, UTMO, UTMT, MGRS, USNG, GEOREF, GARS, PLUSCODE, OLC.

Four labels belong to airfields instead.

LOC, DEPLOC, ARRLOC and ICAO introduce an airfield code in USMTF, not a coordinate. They are claimed by the airfield decorator.

USNG is a label rather than a format of its own. USNG is MGRS on WGS 84 character for character, so a separate format id would make the name on the page a guess.

A genuine USMTF set line is left alone.

A set line ends //, and the trailing boundary rule refuses a slash, so LATM:2130N15730W// is never decorated in the first place. The label is only consumed where the text is prose rather than a message set.

Military grid references

Setting: EnableLocationMGRS

ExampleNotes
4Q FJ 09060 59620MGRS at 1 m, spaced into its parts
4QFJ0906059620and run together, in upper case with five digits an axis
55P BR 76 02a 1 km square rather than a point
5Q KB 80970 82920
MGRS:4QFJ0959coarser than 100 m needs its label

A grid reference is validated by geometry, not just by shape. Only eight of the twenty-four column letters are legal in any given zone, and the square has to lie inside the band the token claims. A token whose square and band are each real but not real together is declined.

Why a bare grid reference is narrowed

Run together and bare, a grid reference has to compete with commit hashes and part numbers. Two restrictions apply to the bare form only, and both were measured rather than guessed:

RestrictionWhy
Upper case onlyAn any-case pattern matched roughly one in every 3,900 short git hashes. 58cbe40 reads as zone 58, band C, square BE.
At least three digits per axisAt two digits per axis, uppercase alphanumeric runs matched about one in 75,000.

Behind an MGRS: label neither restriction applies, because the label is the author saying what they meant.

UTM

Setting: EnableLocationUTM, which ships off

ExampleNotes
4Q 609060 2359620zone, band, easting, northing
55P 276020E 1502660Nthe axis letters are optional, and may carry a meter unit
11S 385000 3769000N and S are read as latitude bands, not as hemispheres
UTMO:4Q609060 2359620the USMTF grid labels
UTMT:4Q6090602359620run together, which is label-only for UTM

The letter is a band, not a hemisphere

In 11S 385000 3769000, the S is latitude band S, at about 34 degrees north. It does not mean "zone 11, southern hemisphere". That is a convention chosen for a military audience rather than a deduction, and its cost is asymmetric: read as a band, a northern token lands in the same place either way, while a southern one can be wrong by up to 90 degrees of latitude.

The northing has to fall inside the band the token names, which declines roughly nine in ten civilian southern-hemisphere tokens rather than placing them wrongly.

Axis letters must sit against their digits. In 11S 384640 3769080 East the token stops before East, so the word is left in the sentence.

Area references

Settings: EnableLocationGEOREF, EnableLocationGARS and EnableLocationPlusCode

These three name a cell rather than a point. GEOREF and GARS are recognized behind their labels only; a Plus Code needs none, because its alphabet and its + are distinctive enough on their own.

ExampleNotes

GEOREF is written longitude first, which is the standard's own order and the opposite of every other grammar on this page.

Each of the three has a resolution ladder: more characters name a smaller cell. The panel says which cell size a token named, and reads the position at its center.

Drawn as a map in the channel

Setting: EnableLocationMapInline

A message whose whole text is one coordinate gets a map drawn under it, with or without a field label. Anything else in the message and it gets the link alone:

ExampleNotes
21.3353, -157.9483a message that is only a coordinate draws its map below it
MGRS: 4QFJ0906059620a field label in front of it still counts
2120N15757Wany grammar, so long as it is the whole message
target at 55P BR 76 02anything else in the message and it is the link alone
4Q FJ 09060 59620 55P BR 76 02two coordinates, so neither one is the message

An inline map changes what the post is.

Drawing the map sets the post's type, and a typed post loses its Elasticsearch and OpenSearch matches, its auto-translation, its embeds and its file attachment list. That is why it is limited to messages that are nothing but a coordinate, and why EnableLocationMapInline exists to turn it off.

Choosing which rows you see

You can hide any row you never use, and the choice is yours alone: it changes nothing for anybody else reading the same message. Hiding every row is allowed and leaves the map. See Customize your view for where the controls live and how to restore the defaults.

Row choices are stored per reader rather than per message, so they follow you to every coordinate you open.

When a conversion does not arrive

The rows are converted by the server. Until that answer arrives, or if it never does, the panel shows the reading it already has and marks the rest as unavailable rather than blanking the panel or showing a spinner in place of a position.

The position itself never depends on the conversion: As written and the map are drawn from what the link carries. A failed conversion costs you the alternative notations, not the coordinate.

Resolution is not accuracy

Every row renders at the resolution the token carried and no finer. Padding a field the author never wrote would be a claim the plugin is not entitled to make. Values round rather than truncate, except grid and area cells, which are chosen by containment.

A value renders at its own axis's digits while the Resolution row reports the coarser half of the pair. 21.3353N 157.9W shows both halves as written and calls the resolution about 11 kilometers. That is telling the truth twice, not contradicting itself.

Resolution says how precisely the position was written. It says nothing about how accurately it was measured.

Naming the country

The panel names the country a position falls in, from outlines compiled into the plugin at about 1:110 million. That is coarse on purpose: it is a label, not a border ruling, and near a coastline or a disputed boundary it can be wrong by roughly a kilometer. The row names its source so the reader can weigh it.

Grid rows name squares

The two grid rows are blank above 84 north and below 80 south, which is Universal Polar Stereographic territory that MGRS and UTM do not cover. The three area rows still render there.

The map

Settings: EnableLocationMap and the three surfaces under it

The basemap is bundled with the plugin rather than fetched, so it draws on a host with no route out.

The hover card

Hovering a coordinate shows the map and nothing else. A hover answers "where is this" at a glance, which for a coordinate is a picture rather than a number. Every reading is a click away in the panel.

The hover map obeys EnableLocationMapPanel, the same switch as the panel's own map. With maps off, hovering a coordinate shows nothing and clicking still opens the full panel.

Map switches are read when the map is drawn.

Unlike format switches, which govern decoration only, the map switches reach links that were written long ago. A map is drawn afresh every time somebody looks and is written into nothing, so turning one off has to take effect everywhere at once.
