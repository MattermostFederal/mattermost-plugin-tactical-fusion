Recognized Formats

The rules every decorator shares, and where to find each one in full.

Each decorator has its own page, listed below and in the sidebar. This page holds what is true of all of them. To see the current behavior of your own server rather than what these pages say, run /tactical-fusion examples, which runs the real matcher and posts what it did.

Rules they all follow

A token needs clean edges

A token is recognized only when what sits immediately either side of it is not a letter, a digit, or one of . , - + / : _. The start and the end of a message count as clean.

That single rule is why logs/ICAO:KIND, X091630ZAUG26, snapshot_3510N07901W_v2.zip and -118.2500..-118.2600 are all left alone. Rewriting the middle of a path, an identifier or a range is the failure these guards exist to prevent.

A label is consumed, and vouches for nothing

Every decorator here accepts field labels: DTG: for times, the USMTF labels for coordinates, and ICAO:, LOC:, DEPLOC: and ARRLOC: for airfields. The label is matched and then dropped, so the link text is the token alone.

A label does not widen what is accepted.

A token behind a label still has to be a real one. DTG: 091630R, LATM:9999N99999W, GARS:721LT and ICAO:KIN are all declined exactly as they would be without the label. What a label changes is whether a token is looked for, never whether it is valid.

A label cannot cross a line break

Only spaces and tabs may sit between a label and its token. A label at the end of one line never claims the first word of the next, so Divert to LOC: followed by FAST movers inbound is left exactly as written.

Spans that are never rewritten

The matcher protects spans, not whole messages. A token in ordinary prose is still linked even when the message also contains a code block or a URL; a token inside one of those is left alone. So this: 

[the plan](https://example.com/brief) says 091630ZAUG26

links the date-time group and leaves the existing link untouched.

The protected constructs are:

  • Fenced code blocks, including unterminated ones and ~~~ fences
  • Indented code blocks
  • Inline code of any backtick width
  • Links, images, and reference definitions
  • Any bracketed span
  • Angle autolinks, such as <https://example.com>
  • Inline HTML tags
  • Bare URLs beginning scheme:// or www.

Decoration is also skipped entirely, leaving the message exactly as written, when the result would exceed the maximum post size. A twelve character date-time group becomes roughly a hundred and twenty once linked, so a message that visibly fits can cross the limit here. Posting it undecorated is better than showing the author an opaque "too long" error for text they can see fits.
