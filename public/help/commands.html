Slash Commands

One trigger, /tactical-fusion, with one subcommand.

CommandDoesWho can run it
/tactical-fusion examples Posts a live demonstration of what the decorators recognise and what they leave alone Any user

Every response is ephemeral: only you see it, and it is not stored in the channel.

/tactical-fusion examples

Arguments

None.

What it shows

Each example appears twice, first raw in a code fence and then as it would be stored after decoration. The output has four sections:

RecognisedWhat each supported format becomes, including a live example resolved against the current time.
DeclinedThe near misses, shown unchanged so you can see they really are declined.
Left as writtenTokens inside protected spans such as code fences and links.
Standalone pageA ready-made link that opens the server-rendered page rather than the sidebar, so you can check it from a desktop browser.

The output is genuinely the matcher's, not a hand-written table.

The command runs the matcher itself rather than relying on the message hook, because its own output is full of code fences and links and so would be skipped. That is also what keeps the "Declined" rows honest: they are the real result, so they cannot drift away from the code.

When decoration is off

If EnableDTG or every format beneath it is switched off, the output ends with a note saying so. Everything in the Recognised section will appear undecorated, which is the correct result rather than a failure.

Before the plugin has finished activating

Run in the moment between the plugin loading and its decorators being registered, the command replies: 

Decorators are not registered yet. Try again once the plugin has finished activating. (TF-16001)
