Slash Commands

One trigger, /tactical-fusion, with three subcommands.

CommandDoesWho sees it
/tactical-fusion examples Posts a short demonstration, one row per format, as a single message Everyone in the channel
/tactical-fusion example-details Posts every format, every edge case and every near miss that is deliberately declined, one message per decorator Everyone in the channel
/tactical-fusion check <text> Shows what would happen to a specific message, and why nothing happened when nothing did You only

Two of these write to the channel.

examples and example-details create real posts that everybody can see and that stay in the channel. Only check is ephemeral. Run the first two where you mean to: the short one is a handful of rows, the detailed one is a post per decorator.

/tactical-fusion examples

Arguments

None.

What it is for

Introducing the plugin to a channel. It posts one message with a row per format, each showing what you would type and the link it becomes, so a team can click through them without every person having to run a command of their own.

The rows read like this, one per format: 

Date/Time: `121411ZAUG26` → 121411ZAUG26 - 5 minutes out, so the countdown opens flagged as imminent
MGRS: `18S UJ 23478 06483` → 18S UJ 23478 06483

The two date-time rows are generated from the moment you run it, one five minutes ahead and one four hours behind. That pair is deliberate: five minutes is inside the flash threshold, so the countdown opens already warning, and four hours behind counts up rather than down, which is the half of the behavior nobody expects until they meet it. A fixed date can show neither.

What it does not show

Nothing exotic, and no near misses. Every boundary case, declined shape and protected span is in example-details. This one is a single post that everybody reads, so it answers one question: what does this plugin do to a message?

When a format is switched off

Its row is left out rather than posted undecorated. A row showing a bare token with no link would be a permanent post advertising that the plugin does nothing. UTM is off by default, so its row is normally absent until an admin turns it on.

With every format off there is nothing left to show, and the command declines rather than posting an empty message. That reply is ephemeral, so a misfire never reaches the channel: 

Nothing would be decorated, so there is nothing to show. Every format is switched off in the System Console, under Plugins > Tactical Fusion. (TF-16003)

/tactical-fusion example-details

Arguments

None. It shows every decorator.

This is the exhaustive one. Where examples shows the ordinary shape of each format in a single post, this shows every format, every boundary, and every near miss that is deliberately declined, with the reason on each row. It is long, and being long is the point: the rows that decline are worth as much as the rows that do not.

It posts one message per decorator.

Two separate posts: one for date-time groups and one for coordinates. Not a thread, because each is a reference you come back to rather than a remark about the one before it. Together they run to around 17,500 characters, which is more than a single post can hold.

On a server with a smaller post size limit a decorator's own examples split further, and the heading is numbered (1 of 3) when that happens. An unnumbered heading means the whole of that decorator is in the post you are reading. Nothing is ever truncated.

A subpath install puts the subpath into every link, and there are a great many links here, which is the one thing that meaningfully changes how many messages it takes.

What it shows

Each row is the text you would type, then the arrow, then what would be stored. No arrow means nothing changed. Rows are grouped under a heading that states the rule they share, which for a declined row is the whole content of the row:

Live, from the moment you ran thisDate-time groups generated against the current clock, either side of the flash threshold and one in the past, so the countdown is actually moving.
One group per grammarMilitary date-time groups, zone letters, RFC 3339 timestamps, the DTG: moniker, decimal degrees, degrees and minutes and seconds, the USMTF compact family, grid references, and UTM.
In a sentenceTokens surrounded by ordinary prose, two on one line, and two different decorators on one line.
DeclinedThe near misses, in groups by what is wrong with them: impossible dates, no single instant, out of range, needs a label or spacing, and shapes where a false positive would rewrite the message.
Left exactly as writtenTokens inside protected spans: code, links, images, autolinks, HTML tags, reference definitions and bare URLs.
Standalone pageA ready-made link that opens the server-rendered page rather than the sidebar, so you can check it from a desktop browser.

The output is genuinely the matcher's, not a hand-written table.

The command runs the matcher itself rather than relying on the message hook, because its own output is full of code fences and links and so would be skipped. That is also what keeps the "Declined" rows honest: they are the real result, so they cannot drift away from the code. A format that is switched off, such as UTM, therefore shows its rows with no link, under a heading that says so.

When it cannot post

A channel that refuses the root post leaves nothing written and the reason is reported to you alone. A reply that is refused costs its own examples only: the rest are still attempted, and you are told how many are missing. Both carry TF-16006.

/tactical-fusion check

Arguments

The text to test, which may contain spaces and may be a whole message. It is not posted anywhere: the command tests it and replies to you alone.

What it is for

Decoration cannot explain itself. A coordinate that is recognized turns into a link and is obviously working; one that is declined does nothing at all, and nothing about the non-event says which rule decided it. 34.0561, -118.2500 is linked and 34.0561, -118.25 is not, and the difference is two characters that nobody would think to count.

This is the command for that. Paste the message that did not work and it will show what would be stored, or say that nothing would be, and list the rules that most often decide it.

What it shows

You typedThe text exactly as supplied.
Would be stored asThe decorated result, when anything matched. Anything still plain in that line was left alone.
Nothing would be decoratedShown instead, when nothing matched at all.
ReasonsThe rules that most often decline a coordinate, with the full list linked.

This runs the real matcher.

Same code path as a posted message, so the answer is what would actually happen and not an approximation of it. That includes the current admin settings, so a format switched off shows up here as nothing matching.

When decoration is off

If EnableDTG or every format beneath it is switched off, the output ends with a note saying so. Everything in the Recognized section will appear undecorated, which is the correct result rather than a failure.

Before the plugin has finished activating

Run in the moment between the plugin loading and its decorators being registered, the command replies: 

Decorators are not registered yet. Try again once the plugin has finished activating. (TF-16002)
