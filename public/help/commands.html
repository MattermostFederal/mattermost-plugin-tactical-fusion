Slash Commands

One trigger, /tactical-fusion, with two subcommands.

CommandDoesWho sees it
/tactical-fusion examples Posts a demonstration, one message per format, plus two Cursor on Target events as cards Everyone in the channel
/tactical-fusion check <text> Shows what would happen to a specific message, and why nothing happened when nothing did You only

One of these writes to the channel.

examples creates real posts that everybody can see and that stay in the channel, one per format and one per Cursor on Target event. check is ephemeral. Run examples where you mean to.

/tactical-fusion examples

Arguments

None.

What it is for

Introducing the plugin to a channel. It posts one message per format, each row showing what you would type and the link it becomes, so a team can click through them without every person having to run a command of their own.

Five posts, and none of them a reply: date-time groups, coordinates, airfields, and then two Cursor on Target events, which arrive as cards. Each is something you come back to rather than a remark on the one above it. A set with nothing left to show is not posted at all.

The rows read like this, one per format: 

Date/Time: `121411ZAUG26` → 121411ZAUG26 - 5 minutes out, so the countdown opens flagged as imminent
MGRS: `4Q FJ 0906 5962` → 4Q FJ 0906 5962
GEOREF: `GEOREF:XGKP55803503` → GEOREF:XGKP55803503 - the label is required, longitude comes first, and this one is on Guam

The GEOREF row shows the other thing worth noticing: a coordinate field label is consumed, so the label and the token together become the link. GEOREF and GARS are matched behind their labels only; a Plus Code needs none.

The two date-time rows are generated from the moment you run it, one five minutes ahead and one four hours behind. That pair is deliberate: five minutes is inside the flash threshold, so the countdown opens already warning, and four hours behind counts up rather than down, which is the half of the behavior nobody expects until they meet it. A fixed date can show neither.

What it does not show

Nothing exotic, and no near misses. Every boundary case, declined shape and protected span is on the format pages: date-time groups, coordinates and airfields each list theirs, with the reason on every row. These posts are read by a whole channel, so they answer one question: what does this plugin do to a message?

When a format is switched off

Its row is left out rather than posted undecorated. A row showing a bare token with no link would be a permanent post advertising that the plugin does nothing. UTM is off by default, so its row is normally absent until an admin turns it on.

With every format off there is nothing left to show, and the command declines rather than posting an empty message. That reply is ephemeral, so a misfire never reaches the channel: 

Nothing would be decorated, so there is nothing to show. Every format is switched off in the System Console, under Plugins > Tactical Fusion. (TF-16003)

/tactical-fusion check

Arguments

The text to test, which may contain spaces and may be a whole message. It is not posted anywhere: the command tests it and replies to you alone.

What it is for

Decoration cannot explain itself. A coordinate that is recognized turns into a link and is obviously working; one that is declined does nothing at all, and nothing about the non-event says which rule decided it. 21.3353, -157.9483 is linked and 21.3353, -157.95 is not, and the difference is two characters that nobody would think to count.

This is the command for that. Paste the message that did not work and it will show what would be stored, or say that nothing would be, and list the rules that most often decide it.

What it shows

You typedThe text exactly as supplied.
Would be stored asThe decorated result, when anything matched. Anything still plain in that line was left alone.
Nothing would be decoratedShown instead, when nothing matched at all.
ReasonsThe rules that most often decline a coordinate, with the full list linked.

This runs the real matcher.

Same code path as a posted message, so the answer is what would actually happen and not an approximation of it. That includes the current admin settings, so a format switched off shows up here as nothing matching.

When decoration is off

If EnableDTG or every format beneath it is switched off, the output ends with a note saying so. Everything in the Recognized section will appear undecorated, which is the correct result rather than a failure.

Before the plugin has finished activating

Run in the moment between the plugin loading and its decorators being registered, the command replies: 

Decorators are not registered yet. Try again once the plugin has finished activating. (TF-16002)
